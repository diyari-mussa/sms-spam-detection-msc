# Notice

This repository is a historical archive of a Master of Science project. Different materials in it are covered in different ways.

## Software

The MIT License in [LICENSE](LICENSE) applies to the source code written for this degree: the Python scripts, the Windows Forms application, the Flask API, and the Android demo.

## Thesis

The thesis PDF in [docs/thesis](docs/thesis) is included by the author, Diyari Jalal Mussa, so readers can consult the full text with the code. That PDF is the February 2020 thesis submitted to the Technical College of Informatics, Sulaimani Polytechnic University. It is not released under the MIT License.

Thesis title: *SMS Spam Detection System Using Hybrid Gradient Boosting with Wrapper Algorithms*.

## Journal article

The December 2019 article is the version of record at Kurdistan Journal of Applied Research. This repository links to it and does not redistribute the journal PDF.

Mussa, D. J., & Jameel, N. G. M. (2019). Relevant SMS spam feature selection using wrapper approach and XGBoost algorithm. *Kurdistan Journal of Applied Research, 4*(2), 112–120. https://doi.org/10.24017/science.2019.2.11

## Dataset

The SMS Spam Collection is not included in this repository. The experiments used SMS Spam Collection v.1 (4,827 ham messages and 747 spam messages). Download it from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/ml/datasets/sms+spam+collection).

If you use that corpus, cite:

Almeida, T. A., Hidalgo, J. M. G., & Yamakami, A. (2011). Contributions to the study of SMS spam filtering: New collection and results. *Proceedings of the 2011 ACM Symposium on Document Engineering (DocEng '11)*, Mountain View, CA, USA.
